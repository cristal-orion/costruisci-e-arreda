COPIA STATICA DI COSTRUISCIEARREDA.IT

Homepage:
  costruisciearreda.it/index.html

Per visualizzarla correttamente avviare un server locale dalla cartella costruisciearreda.it.
Esempio con Python:
  cd costruisciearreda.it
  python3 -m http.server 8080

Poi aprire:
  http://localhost:8080/

Nota: è una copia del frontend pubblico. Funzioni WordPress/server (moduli, ricerca dinamica,
login, API e invio email) possono non funzionare offline.
